# Scribble Map

  Browser extension for crawling websites into a HTML overview.

## Download

  [Download Scribble Map latest](https://raw.githubusercontent.com/teabeg-ger/scribble-map-releases/main/scribble_map-latest.xpi)

### Installation

  1. Download the `.xpi` file above, should auto install when opened, if not -> follow next steps
  2. Open Firefox and go to `about:addons`
  3. Gear icon → "Install Add-on From File" → select the `.xpi`

### Supported Browsers

- Firefox (this release)
- Chrome/Edge (coming soon)
